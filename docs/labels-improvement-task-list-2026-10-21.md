# Labels 改进任务清单

更新时间：2026-10-21

## P0：先修稳定性

- [ ] 将 Lock 相册查看器中的 `Lock` 改为 `Unlock`。
  - 点击后执行现有的 `restoreFromVault()`，把媒体移出 Lock 文件夹并恢复到原目录。
  - 修复此前移出 Lock 的路径，确认不会停留在 Lock 文件夹或因路径/索引更新失败而无效。
- [ ] 增加 Lock 相册查看器回归测试：进入图片、展开操作栏、点击 Unlock，确认不闪退、媒体从 Lock 消失并回到原目录。
- [ ] 修复 Bin 中“一键清除 Empty”无响应的问题。
  - 保留主动选中后删除的现有行为。
  - 覆盖 Empty 为空、只有 Empty、Empty 与普通回收站项目混合三种情况。

## P1：Labels Grid 与相册 Grid 对齐

- [ ] Labels 总览页右上角增加更多菜单。
  - `Sort`：名称、使用数量、自定义顺序。
  - `Settings`：进入标签管理。
- [ ] 标签总览页补齐相册 Grid 的通用体验：搜索、网格列数调整、滚动条和稳定的空状态。
- [ ] 复用现有 `sortOrder`，实现自定义标签顺序并持久化。
- [ ] 进入某个标签后的 Label Album Grid 复用普通相册图片页能力。
  - `Sort Photos`。
  - 搜索、图片/视频筛选、网格列数调整、多选、查看器、Quick Sort。
- [ ] 标签图片页不提供去重、隐藏相册、移入 Lock 文件夹。
- [ ] 增加“从当前标签移除媒体”和“编辑标签”两个标签专属操作。

## P1：标签编辑体验

- [ ] 添加/编辑标签面板保留三态复选框列表。
- [ ] 增加搜索、已选标签置顶、最近使用和分组，降低大量标签下的滚动成本。
- [ ] 新建标签入口与搜索结果联动，并保持同名校验。

## P1：Info 页职责收敛

- [ ] 保留 Info 页的当前媒体标签摘要，不复制标签管理逻辑。
- [ ] 标签 chip 用于查看/跳转；“编辑标签”打开同一个编辑面板。
- [ ] 没有标签时显示“添加标签”，避免出现空的重复区域。

## 数据与实现

- [ ] 为 Labels ViewModel 增加排序模式、搜索状态和标签重排操作。
- [ ] 为 LabelDao/Repository 增加批量更新 `sortOrder` 的事务操作。
- [ ] 标签名称继续保持规范化唯一；允许同一标签关联多个媒体，不允许同名标签实体。
- [ ] 复用普通相册的 `PhotoSortOrder` 和排序组件，避免标签图片页产生另一套排序逻辑。

## 最终验收

- [ ] 标签排序在应用重启后保持。
- [ ] 100 个以上标签仍可通过搜索、排序和管理页操作。
- [ ] 空标签可删除，删除只移除标签关系，不删除媒体文件。
- [ ] 同一标签可关联多个媒体，同一媒体可拥有多个标签。
- [ ] Info 页、标签编辑面板、Labels Grid 显示同一份实时数据。
- [ ] 普通相册 Grid 与 Label Album Grid 的排序、筛选、选择和查看器行为一致。
- [ ] Lock 相册查看器显示 Unlock，恢复路径通过真实设备测试。
- [ ] Bin 的一键清除 Empty 真正执行清理，并与手动选中删除结果一致。

## 2026-10-21 断线续做记录

本轮已完成代码实现并通过 `:app:compileDebugKotlin` 与 `:app:testDebugUnitTest`（169 项 JVM 测试）：

- Lock 查看器按来源显示 `Unlock`，调用已有 `restoreFromVault` 并退出查看器；批量恢复入口保持不变。
- Bin 的 `Empty` 接入统一的永久删除确认流程，空 Bin、单项和混合回收站项目都通过同一批量删除路径。
- Labels 总览增加搜索、滚动条、列数调整、名称/使用量/自定义排序菜单；自定义顺序写入 `labels.sortOrder`，上下移动可持久化。
- Label Album Grid 增加文件搜索、图片/视频筛选、`Sort Photos`、编辑标签及从当前标签移除已选媒体；没有加入去重、隐藏或 Lock 操作。
- 标签编辑原有三态复选框和搜索保留；同名规范化校验与批量关系更新保持不变。

设备连接在本轮不可用，以下项目仍需真实 Android UI 回归后才能划线：Lock 图片进入/Unlock 后文件与索引回归、Bin 三种数据形态的实际清理、标签排序重启保持、100+ 标签操作，以及 Info 页与标签页的真实交互一致性。
