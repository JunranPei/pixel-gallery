轻微弹性稳定落定

进入 Lock / Hidden 后，当前入口保持可见。点普通标签或系统返回再收起；不设自动消失倒计时。原型中的私有页面仅示意布局，正式版本沿用原认证和数据规则。

还可以比较的取舍

若希望展开后一直保留，可关闭“操作主体时收起”，只靠反向拖动、普通标签和返回收回。

同时展开四项也可做，但会让未拖动的一侧一起出现，导航占宽也更大，因此本稿先采用三项。
