# Pixel Gallery 媒体转移功能 PRD

- 状态：已确认，进入实现
- 日期：2026-08-02
- 范围：图片与视频的移动、复制及目标位置选择

## 1. 背景

Pixel Gallery 当前支持分享、删除、收藏及移入锁定文件夹，但无法把普通媒体整理到其他相册或文件夹。Simple Gallery 已提供成熟的目录搜索与目标选择体验，本功能借鉴其信息架构，但使用 Pixel 现有的 Material 3 / Material 3 Expressive 视觉语言重新设计，不直接移植其对话框页面或代码。

## 2. 产品目标

1. 单张查看和网格多选使用同一套“移动或复制到”能力。
2. 用户可通过搜索快速找到已有相册，也可浏览其他文件夹或新建文件夹。
3. 移动和复制是同一级别的最终操作，目标确认前不预设操作类型。
4. 操作过程安全、可恢复理解；任何失败不得导致源文件和目标文件同时丢失。
5. 操作完成后 Pixel 的相册、当前列表和收藏状态保持一致。

## 3. 非目标

- 不支持把回收站、锁定文件夹或外部临时打开的媒体直接转移。
- 不实现云端相册、跨设备传输或网络目标。
- 不照搬 Simple Gallery 的 AlertDialog、旧式工具栏或 RecyclerView 样式。
- 本期不支持移动整个相册文件夹，仅处理选中的媒体文件。

## 4. 入口

### 4.1 单张 Viewer

右上角更多菜单新增“移动或复制到…”，位于“设置为壁纸”和“移动到锁定文件夹”之间。Viewer 底部现有五个主操作保持不变。

### 4.2 网格多选

普通照片、相册内照片和收藏页面进入多选后，顶部保留“分享”“删除”“更多”。“移动到锁定文件夹”移入更多菜单，并与“移动或复制到…”并列。

回收站与锁定文件夹保持各自现有专用操作，不显示媒体转移入口。

## 5. 核心流程

1. 用户选择一项或多项媒体。
2. 点击“移动或复制到…”。
3. 进入独立的“选择目标位置”页面。
4. 用户可搜索相册、浏览文件夹或新建文件夹。
5. 用户选中一个目标位置。
6. 页面底部显示目标摘要以及“复制到这里”“移动到这里”两个平级操作。
7. 用户选择操作后进入处理中状态。
8. 完成后返回来源页面，并显示成功、跳过和失败数量。

## 6. 功能需求

| 编号 | 需求 |
|---|---|
| TR-01 | 入口统一命名为“移动或复制到…”。 |
| TR-02 | 单选和多选使用同一目标选择页面与传输引擎。 |
| TR-03 | 默认展示 Pixel 已识别的相册，目标以完整路径标识。 |
| TR-04 | 搜索按相册名和路径匹配，不区分大小写。 |
| TR-05 | 同名相册必须显示父路径，避免选错目标。 |
| TR-06 | 支持通过“浏览其他文件夹”选择未被 Pixel 识别为相册的目录。 |
| TR-07 | 支持在当前可写位置新建文件夹；创建后自动选中但不自动执行。 |
| TR-08 | 移动和复制按钮等宽、同级，只有目标有效时才可用。 |
| TR-09 | 单来源选择时，源目录不可作为移动目标；复制到原目录需进入冲突处理。 |
| TR-10 | 多来源选择允许选择其中一个源目录，同目录项目按冲突规则处理。 |
| TR-11 | 文件重名支持“保留两份”“跳过”“替换”，默认“保留两份”，并可应用到本批次。 |
| TR-12 | 操作中显示模式、目标、已完成数量与总数量，禁止重复提交。 |
| TR-13 | 完成后反馈成功、跳过和失败数量；失败时保留可理解的原因。 |
| TR-14 | 权限被拒绝或系统选择器取消时，保留原选择，不启动传输。 |
| TR-15 | 移动收藏媒体后收藏状态保持；复制出的新项目默认不自动收藏。 |
| TR-16 | 移动成功后 Viewer 返回来源网格；批量操作成功后清空选择。 |

## 7. 状态与异常

- 空相册：可作为目标，但相册列表中的空目录只在本次新建或文件系统浏览时出现。
- 存储空间不足：执行前尽可能检查，执行中失败不得删除源文件。
- 跨存储卷：使用安全复制并在目标提交成功后删除源文件。
- 部分成功：不回滚已成功项目，结果摘要明确显示部分完成。
- 应用转入后台：页面保留进度状态；本期不承诺进程被系统杀死后自动继续。
- 同名文件：在第一次冲突时请求处理方式，可选择应用到全部冲突。

## 8. 成功指标

- 用户可在单张和多选场景完成移动或复制。
- 移动后无重复旧条目、黑屏 Viewer 或收藏丢失。
- 权限拒绝、空间不足、跨卷失败时不存在源文件丢失。
- 目标搜索能区分同名不同路径相册。
- Android 8、10、11、13 和 15 的关键流程通过验收。

## 9. 发布边界

首个可发布版本必须同时具备：统一入口、MD3 目标页、已有相册搜索、新建文件夹、移动、复制、冲突处理、操作结果和刷新一致性。“浏览其他文件夹”若因特定设备的系统文档提供器不可用，应明确禁用并提示，而不是退化为不安全的裸路径写入。
