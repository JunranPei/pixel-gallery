# 媒体转移 UI 与交互规范

## 1. 设计原则

- 借鉴 Simple Gallery 的“相册优先、常驻搜索、可进入其他文件夹”信息架构。
- 延续 Pixel 的 Material 3 动态色、大圆角封面和强调型标题，不复制 Simple 的弹窗外观。
- 目标位置和最终动作同时可见，避免选完目标后再弹出一层“移动还是复制”的确认框。
- 不改变 Viewer 底部五按钮和现有网格手势。

## 2. 页面结构

页面为独立全屏目的地；大屏和横屏可限制内容最大宽度，但仍保持页面语义，不改成窄 AlertDialog。

### 2.1 顶部应用栏

- 左侧：返回。
- 标题：`选择目标位置`。
- 右侧：`新建文件夹`图标按钮。
- 使用普通 `TopAppBar`，遵循状态栏安全区。

### 2.2 搜索

- 搜索框常驻在应用栏下方，不隐藏在搜索图标内。
- 提示文字：`搜索相册或文件夹`。
- 左侧搜索图标；有内容时右侧显示清除按钮。
- 使用 MD3 `surfaceContainerHigh` 容器、28dp 圆角；高度 56dp；水平边距 16dp。
- 搜索匹配相册名称与规范化路径；结果仍使用相册卡片，不切换成另一套视觉。

### 2.3 快捷入口

搜索框下方显示两个可按状态出现的快捷项：

- `浏览其他文件夹`：进入目录层级或系统目录选择器。
- `新建文件夹`：与顶部加号等价；在当前浏览位置创建。

使用 `FilledTonalButton` 或大圆角辅助卡片，不与相册封面争夺视觉主次。

### 2.4 相册网格

- 竖屏默认 2 列；紧凑宽度最少保证卡片 148dp；大屏自适应增加列数。
- 卡片封面为 1:1，使用 `ExpressiveShapes.ExtraLargeIncreased`（32dp 圆角）。
- 标题使用 `titleMedium`/加粗，最多一行，中间省略。
- 第二行显示媒体数量。
- 同名相册或搜索结果第三行显示父路径；其他情况下可省略路径以保持简洁。
- 目标卡片选中后使用 `primary` 2dp 描边、右上角选中标记和轻微 `primaryContainer` 底色。
- 当前唯一源目录在移动语义下标注“当前位置”；仍允许用户选择并执行复制，由冲突处理决定结果。

### 2.5 文件夹浏览模式

- 顶部标题保持不变，搜索框下方显示路径面包屑。
- 文件夹项目优先使用列表形式，显示文件夹图标、名称和简化路径；相册文件夹可显示小封面。
- 点击文件夹进入下一级；底部操作始终针对当前文件夹。
- 系统不允许访问的位置显示禁用状态和原因，不静默失败。

### 2.6 固定底部操作区

- 未选中目标时显示提示：`选择一个目标位置`，两个按钮禁用。
- 选中后显示一行目标名称和一行中间省略的完整路径。
- `复制到这里`和`移动到这里`左右等宽，间距 12dp。
- 两个操作同级：都使用 `FilledTonalButton`；移动按钮可使用更高强调的 `Button` 仅在可访问性对比度需要时启用，但不得用错误/红色表达。
- 底部区域使用 `surfaceContainer`、顶部 1dp 分隔或轻微 tonal elevation，并适配导航栏 Insets。

## 3. 入口菜单

### Viewer 更多菜单

1. 设置为壁纸
2. 移动或复制到…
3. 移动到锁定文件夹
4. 打开方式

### 多选顶部栏

- 可见：分享、删除、更多。
- 更多：移动或复制到…、移动到锁定文件夹。
- 回收站与锁定文件夹不显示转移项。

## 4. 对话框与反馈

### 新建文件夹

- MD3 `AlertDialog`。
- 单行名称输入；实时校验空白、路径分隔符、保留名称和同名目录。
- 按钮：取消、创建。
- 创建成功后关闭对话框并自动选择新目录。

### 文件冲突

- 标题：`目标中已有同名项目`。
- 显示文件名和目标相册。
- 单选项：保留两份（默认）、跳过、替换。
- 多文件时提供“应用到所有冲突”。

### 处理中

- 页面内容保留，叠加不可重复提交的进度区域。
- 显示 `正在移动 3 / 12` 或 `正在复制 3 / 12`。
- 首版不提供中途取消，以避免在文件提交边界产生模糊状态。

### 结果

- 全部成功：Snackbar，例如“已移动 12 个项目”。
- 部分成功：较长 Snackbar，例如“已移动 10 个，跳过 1 个，失败 1 个”，提供“查看”以展开原因。
- 全部失败：保留选择和当前页面，显示明确错误，不自动退出。

## 5. 动效与无障碍

- 选中卡片使用 150–200ms 颜色、描边和勾选淡入，不缩放封面以避免图片跳动。
- 搜索结果使用稳定 key，不在输入时播放整页入场动画。
- 所有图标按钮必须提供 content description。
- 触控目标不小于 48dp；正文和路径支持系统字体缩放。
- TalkBack 读取顺序：相册名、媒体数量、父路径、是否已选中。
- 深色模式、动态色关闭模式和高对比度下均不得依赖颜色作为唯一选中标识。

## 6. 文案基线

| 场景 | 文案 |
|---|---|
| 统一入口 | 移动或复制到… |
| 页面标题 | 选择目标位置 |
| 搜索提示 | 搜索相册或文件夹 |
| 其他目录 | 浏览其他文件夹 |
| 空搜索 | 未找到匹配的文件夹 |
| 底部未选择 | 选择一个目标位置 |
| 复制按钮 | 复制到这里 |
| 移动按钮 | 移动到这里 |
| 同一位置 | 源位置和目标位置相同 |
