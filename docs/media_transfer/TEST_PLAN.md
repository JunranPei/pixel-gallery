# 媒体转移验收与测试方案

## 1. 单元测试

- 按完整父路径生成目标相册；同名不同路径不得合并。
- 搜索匹配名称、父路径和完整路径，忽略大小写。
- 文件名拆分覆盖无扩展名、多点文件名、隐藏文件和 Unicode。
- `KEEP_BOTH` 连续生成不冲突名称。
- 多来源请求正确识别同目录项目。
- TransferResult 正确汇总成功、跳过和失败。

## 2. UI 测试

- Viewer 更多菜单和普通多选更多菜单显示统一入口。
- 回收站、锁定文件夹和外部 Viewer 不显示入口。
- 搜索清除、空结果、同名相册路径和选中标记正确。
- 未选目标时底部按钮禁用；选中后两个按钮等宽可用。
- 新建目录校验与自动选中正确。
- 字体 200%、深色模式、动态色关闭和横屏下无裁切。
- TalkBack 能读出相册名称、数量、路径和选中状态。

## 3. 设备矩阵

至少覆盖：

- Android 8/9：传统文件权限与 MediaScanner 路径。
- Android 10：MediaStore `RELATIVE_PATH`。
- Android 11：批量写授权、拒绝与再次尝试。
- Android 13：图片/视频分离读取权限。
- Android 15：targetSdk 35、内部存储和可用 SD 卡。

## 4. 功能场景

| 场景 | 期望 |
|---|---|
| 单张图片移动到已有相册 | 原 URI/ID 尽可能保持，来源消失，目标出现。 |
| 单张视频复制 | 原项保留，新项可播放，时长和 MIME 正确。 |
| 多选图片与视频混合移动 | 全部按序完成，进度和数量正确。 |
| 收藏图片同卷移动 | 收藏状态保持。 |
| 收藏图片跨卷移动 | 新 ID 继承收藏，旧 ID 清理。 |
| 同名相册搜索 | 显示不同父路径，选择目标准确。 |
| 新建空文件夹并复制 | 新目录被选中，复制后成为相册。 |
| 复制到源目录 | 触发冲突规则，不覆盖源。 |
| 多来源移动到其中一个源目录 | 已在目标内的项目按冲突规则处理，其他项移动。 |
| 权限拒绝 | 不执行、不清空选择、源文件不变。 |
| 存储空间不足 | 失败项源文件保留，无残留 pending 项。 |
| 跨卷复制中断 | 源保留，临时目标清理或保持不可见。 |
| Viewer 移动当前项 | 成功后返回网格，无黑屏或失效页面。 |
| Viewer 复制当前项 | 原 Viewer 可继续查看，目标出现副本。 |

## 5. 回归

- 分享、删除、收藏、移入锁定文件夹继续工作。
- Viewer 底部五操作的位置、动画和点击范围不变。
- 相册页滚动位置、网格列数、隐藏和排除操作不受影响。
- MediaStore generation 优化不会跳过转移后的刷新。
- 多开/多任务入口不会共享错误的挂起传输状态。

## 6. 发布门槛

- Debug 与 Release Kotlin 编译通过。
- 单元测试通过；关键 Android 11+ 真机流程通过。
- 不存在源文件丢失、错误覆盖、收藏丢失或 Room/MediaStore 长期不一致。
- PRD 中 TR-01 至 TR-16 均有实现或明确的发布阻断说明。
